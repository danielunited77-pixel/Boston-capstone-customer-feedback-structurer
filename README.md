## Project Overview

This project was developed as part of the PG Diploma in Business Analytics – Real World Capstone Project 2026 in collaboration with Boston India.

The objective of this project is to transform unstructured customer reviews into structured business insights using a Large Language Model (LLM). 
The application automatically classifies customer reviews into predefined business categories using a Large Language Model (LLM), 
enabling organizations to transform unstructured customer feedback into structured insights for analysis and decision-making..

The application classifies every customer review into:

- Sentiment (Positive, Neutral, Negative)
- Issue Category
- Urgency Level
- Reason for Classification

The solution supports both single review analysis and batch review processing through an interactive Streamlit web application.

## Dataset

This project uses the Amazon Unlocked Mobile Reviews Dataset.

The original dataset contains more than **413,000 customer reviews**. For demonstration and validation purposes, 
manually annotated ground truth files and sample outputs are included in this repository.
